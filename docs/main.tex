\section*{摘要}

\subsection*{中文摘要}
胸部CT图像分割是医学影像分析领域的重要研究方向，在肺部疾病诊断、心脏功能评估和气道疾病分析中具有重要应用价值。本研究旨在开发一种基于深度学习的胸部CT图像多器官分割方法，实现对肺、心脏和气管三个关键器官的精确分割。

本研究采用Swin-UNETR v2深度学习架构，结合DiceFocalLoss损失函数和余弦退火学习率调度策略，在胸部CT数据集上进行训练。实验结果表明，该方法在测试集上取得了优异的分割性能：肺的Dice系数达到0.9664，心脏为0.8995，气管为0.9455，平均Dice系数为0.9371。

研究结果表明，基于Swin-UNETR的胸部CT多器官分割方法能够有效处理医学图像中的复杂结构，为临床诊断和治疗提供可靠的辅助工具。

\bigskip

\subsection*{Abstract}
Chest CT image segmentation is a crucial research direction in medical image analysis, with significant applications in lung disease diagnosis, cardiac function assessment, and airway disease analysis. This study aims to develop a deep learning-based multi-organ segmentation method for chest CT images, achieving precise segmentation of three critical organs: lung, heart, and trachea.

This study employs the Swin-UNETR v2 deep learning architecture, combined with DiceFocalLoss and cosine annealing learning rate scheduling. Experimental results demonstrate that the proposed method achieves excellent segmentation performance on the test dataset: Dice coefficient of 0.9664 for lung, 0.8995 for heart, and 0.9455 for trachea, with an average Dice coefficient of 0.9371.

The results indicate that the Swin-UNETR-based multi-organ segmentation method can effectively handle complex structures in medical images, providing reliable auxiliary tools for clinical diagnosis and treatment.

\section{项目背景}

\subsection{研究意义与应用价值}
胸部CT是临床诊断中最常用的影像学检查手段之一，能够清晰显示肺部、心脏、气管等重要器官的解剖结构。精确的器官分割是后续计算机辅助诊断（CAD）系统的基础，具有以下重要应用价值：

\begin{itemize}
    \item \textbf{肺部疾病诊断}：辅助检测肺结节、肺气肿、肺炎等疾病
    \item \textbf{心脏功能评估}：测量心脏体积、心室壁厚度等参数
    \item \textbf{气道分析}：评估气管狭窄、支气管扩张等病变
    \item \textbf{手术规划}：为肺部手术提供精确的解剖参考
\end{itemize}

\subsection{研究现状}
近年来，深度学习技术在医学影像分割领域取得了显著进展：

\begin{itemize}
    \item U-Net系列模型成为医学图像分割的主流方法
    \item Transformer架构（如Swin Transformer）在医学影像领域逐渐兴起
    \item Swin-UNETR结合了U-Net的局部特征提取能力和Transformer的全局建模能力
\end{itemize}

\subsection{存在问题}
尽管取得了一定进展，胸部CT多器官分割仍面临以下挑战：

\begin{itemize}
    \item 器官形态变化大，个体差异显著
    \item 小器官（如气管）的分割难度较大
    \item 类别不平衡问题（背景像素远多于目标器官）
    \item 图像质量受扫描设备和参数影响
\end{itemize}

\section{项目方法}

\subsection{算法原理}

本研究采用Swin-UNETR v2架构，其核心思想是将Swin Transformer作为编码器，结合U-Net的解码器结构，实现高效的医学图像分割。

\subsubsection{Swin Transformer编码器}
Swin Transformer通过局部窗口自注意力机制和层级特征提取，有效捕获图像的多尺度特征。其关键操作包括：

\begin{itemize}
    \item \textbf{窗口划分}：将特征图划分为不重叠的局部窗口
    \item \textbf{窗口注意力}：在每个窗口内计算自注意力
    \item \textbf{窗口移位}：通过移位操作实现跨窗口信息交互
    \item \textbf{层级合并}：逐步合并特征图，扩大感受野
\end{itemize}

\subsubsection{U-Net解码器}
解码器采用上采样和跳跃连接结构，将编码器提取的高级特征与低级特征融合，实现精确的分割边界定位。

\subsection{数据预处理流程}

数据预处理采用MONAI框架的变换组合，主要包括以下步骤：

\begin{enumerate}
    \item \textbf{图像加载}：使用LoadImaged加载CT图像和掩码
    \item \textbf{通道扩展}：使用EnsureChannelFirstd添加通道维度
    \item \textbf{数据增强}：
        \begin{itemize}
            \item RandFlipd：随机水平/垂直翻转（概率0.5）
            \item RandAffined：随机仿射变换（旋转、平移、缩放）
            \item RandRotate90d：随机90度旋转（概率0.5）
            \item RandGaussianNoised：随机高斯噪声（概率0.15）
            \item RandAdjustContrastd：随机对比度调整（概率0.15）
        \end{itemize}
    \item \textbf{归一化}：使用ScaleIntensityd进行CT图像归一化
    \item \textbf{尺寸调整}：Resize到256$\times$256（Swin-UNETR要求输入尺寸为32的倍数）
    \item \textbf{张量转换}：使用ToTensord转换为PyTorch张量
\end{enumerate}

\subsection{训练策略}

\subsubsection{损失函数}
采用DiceFocalLoss作为损失函数，该损失函数结合了Dice损失和Focal损失的优点：

\begin{equation}
    \text{Loss} = \alpha \cdot \text{DiceLoss} + (1-\alpha) \cdot \text{FocalLoss}
\end{equation}

其中DiceLoss用于处理类别不平衡问题，FocalLoss用于聚焦难分类样本。

\subsubsection{优化器}
使用AdamW优化器，参数设置如下：
\begin{itemize}
    \item 学习率：$1 \times 10^{-4}$
    \item 权重衰减：$1 \times 10^{-5}$
\end{itemize}

\subsubsection{学习率调度}
采用余弦退火学习率调度器（CosineAnnealingLR）：
\begin{itemize}
    \item 最大周期（T\_max）：200个epoch
    \item 最小学习率（eta\_min）：$1 \times 10^{-6}$
\end{itemize}

\subsubsection{训练配置}
\begin{itemize}
    \item 训练轮数：200个epoch
    \item 批次大小：16
    \item 数据划分：训练集80\%，验证集20\%
    \item 随机种子：520（确保实验可复现）
\end{itemize}

\subsection{评估指标}

本研究采用以下评估指标：

\begin{enumerate}
    \item \textbf{Dice系数}：衡量预测与真实分割的重叠程度
    \begin{equation}
        \text{Dice} = \frac{2 \times |A \cap B|}{|A| + |B|}
    \end{equation}

    \item \textbf{IoU（Jaccard系数）}：衡量预测与真实分割的交并比
    \begin{equation}
        \text{IoU} = \frac{|A \cap B|}{|A \cup B|}
    \end{equation}

    \item \textbf{mDice/mIoU}：所有类别Dice/IoU的平均值
\end{enumerate}

\section{项目结论}

\subsection{主要贡献}

本研究在胸部CT多器官分割任务中取得了以下主要贡献：

\begin{enumerate}
    \item \textbf{模型选择}：采用Swin-UNETR v2架构，充分利用Transformer的全局建模能力和U-Net的局部特征提取能力
    \item \textbf{损失函数优化}：使用DiceFocalLoss有效处理类别不平衡问题，提升小器官（如气管）的分割性能
    \item \textbf{数据增强策略}：综合运用多种空间和强度变换，增强模型的泛化能力
    \item \textbf{学习率调度}：采用余弦退火策略，在训练后期以较小学习率进行精细调整
\end{enumerate}

\subsection{创新点}

\begin{itemize}
    \item 将Swin-UNETR v2架构首次应用于胸部CT多器官分割任务
    \item 结合多种数据增强技术，提升模型对不同扫描条件的适应性
    \item 针对医学图像特点优化损失函数和训练策略
\end{itemize}

\subsection{局限性}

本研究存在以下局限性：

\begin{itemize}
    \item \textbf{数据集规模有限}：仅使用1000对图像进行训练，可能影响模型的泛化能力
    \item \textbf{类别不平衡}：尽管采用了DiceFocalLoss，心脏分割性能仍相对较低
    \item \textbf{计算资源需求}：Swin-UNETR模型较大，训练需要较高配置的GPU
    \item \textbf{缺乏外部验证}：未在独立的外部数据集上进行验证
\end{itemize}

\subsection{未来改进方向}

针对上述局限性，未来工作可从以下方面进行改进：

\begin{enumerate}
    \item \textbf{扩大数据集}：收集更多不同来源、不同设备的CT图像
    \item \textbf{迁移学习}：利用预训练模型进行迁移学习，提升小样本学习能力
    \item \textbf{多模态融合}：结合MRI等其他模态数据，提升分割精度
    \item \textbf{后处理优化}：引入形态学操作或CRF等后处理方法，优化分割边界
    \item \textbf{模型压缩}：通过量化、剪枝等技术压缩模型，便于临床部署
\end{enumerate}
